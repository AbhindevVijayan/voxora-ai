# High-Fidelity Voiceover Generator

A voice-over generation project designed to produce high-quality audio narration using modern text-to-speech and audio processing techniques.

## Features

- Generate natural-sounding voiceovers
- Support for multiple voices and languages
- Configurable audio quality and output formats
- Modular architecture for easy extension

## Installation

1. Clone the repository
2. Install dependencies
3. Run the generator from the project root

## Usage

Example:
.\run-generator.ps1 --input "script.txt" --voice "studio" --output "voiceover.wav"

## Project Structure

- src/ - implementation code
- models/ - voice model assets
- data/ - sample scripts and resources
